# Security Policy

## Supported versions

This repository is an unversioned collection of engineering resources, skills, and tools. Security updates and bug fixes are applied directly to the default `main` branch.

| Version | Supported |
|---------|-----------|
| `main`  | Yes       |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Report privately through GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab.
2. Select **Report a vulnerability** under **Advisories**.
3. Provide a description, reproduction steps, affected component, and impact.

If you cannot use private reporting, contact [@carlosboeing](https://github.com/carlosboeing) via GitHub with the same detail. Include `agentic-toolkit security` in the subject, or open a draft advisory at https://github.com/carlosboeing/agentic-toolkit/security/advisories/new.

You can expect an initial acknowledgement within 7 days.
