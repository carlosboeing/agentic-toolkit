# Security policy

## Supported versions

The toolkit is not versioned. Fixes, including security fixes, go directly to the `main` branch.

| Version | Supported |
|---------|-----------|
| `main`  | Yes       |

## Reporting a vulnerability

Do not report a vulnerability in a public issue, pull request or discussion. Report it privately through GitHub:

1. Open the repository's **Security** tab.
2. Under **Advisories**, select **Report a vulnerability**, or go directly to [the new advisory form](https://github.com/carlosboeing/agentic-toolkit/security/advisories/new).
3. Describe the problem, the steps to reproduce it, the affected component and its impact.

If you cannot use private reporting, contact [@carlosboeing](https://github.com/carlosboeing) on GitHub with the same details, and include `agentic-toolkit security` in the subject.

You can expect an acknowledgement within 7 days.
