# start-research

Investigate a bounded question before, during, or independently of other lifecycle work. Research supplies evidence, not approval of product scope.

Run `/start-research [question or source-path] [help]` or request its work in natural language. Use `/start-research help` for the synopsis.

The complete procedure is in [SKILL.md](SKILL.md). Project instructions own storage, review, and delivery permissions. Documents, separate sessions, and agents are conditional. The skill stops at its requested boundary unless an explicit workflow already authorizes continuation.

## Dependencies and installation

No additional runtime or service is required. Use the available project and harness capabilities; unavailable capabilities are reported rather than simulated. Git, Bash, and `rsync` are needed for the toolkit installation procedure. Install the complete directory using the [shared instructions](../README.md#install-one-skill). No global installation is performed by invoking this phase.

## Provenance

This procedure evolves the primary-source research technique previously carried by [research](../research/). That compatibility entry retains the [upstream MIT notice](LICENSE); the same notice is included here for standalone installation. The procedure adds optional artifacts and delegation, capability discovery, scoped access, source reconciliation, and explicit stopping conditions.
