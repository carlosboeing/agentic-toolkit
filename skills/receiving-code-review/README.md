# receiving-code-review

Guides the agent when it receives code review feedback: verify each point against the code before acting, push back on wrong suggestions with reasons, and avoid performative agreement. It loads automatically when review feedback arrives.

## Source

A verbatim copy of [`receiving-code-review`](https://github.com/obra/superpowers/blob/2ce8aa15d05bd57213e6f746f953aafb7ded7a8b/skills/receiving-code-review/SKILL.md) from Superpowers at commit `2ce8aa1`, by Jesse Vincent, under the MIT License in [LICENSE](LICENSE). No edits.

The toolkit copies it because no lifecycle skill covers responding to review, and CrossRev's `pr-resolve` skill points to it by name. It keeps the upstream name so that pointer still resolves after Superpowers is uninstalled.
